FEATURED PROJECT · 01

SourceSnap

A privacy-first Chrome extension that turns copied text into an organised source library.

THE PROBLEM

Copied text often loses its original source, leaving students and researchers with uncited notes they cannot trace later.

THE SOLUTION

SourceSnap records copied text with its page title, URL, and date—then exports only the citations a user selects.

BUILT WITH

JavaScript · HTML · CSS
Chrome Manifest V3 · Chrome Storage API

View SourceSnap on GitHub ↗

HOW IT WORKS

01

Copy naturally

Highlight and copy useful text from a webpage as usual.

02

Keep the source

SourceSnap saves the excerpt, page title, link, and capture date locally.

03

Cite selectively

Choose the saved sources you need and export APA, MLA, IEEE, and more.
